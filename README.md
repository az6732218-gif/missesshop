# Misses Styles — متجر كامل + لوحة تحكم

بدون أي مكتبات خارجية. محتاج **Node.js 22.5 أو أحدث** فقط.

## التشغيل
```
ADMIN_USER="اسم-مستخدم-خاص" \
ADMIN_PASSWORD="كلمة-سر-قوية" \
ADMIN_PATH="رابط-سري-للوحة" \
VODAFONE_CASH_NUMBER="01xxxxxxxxx" \
INSTAPAY_ADDRESS="name@instapay" \
node server.js
```
- الموقع: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

لو ما كتبتيش `ADMIN_PASSWORD` السيرفر هيولّد كلمة سر عشوائية ويطبعها في الشاشة أول مرة.
كلمة السر بتتخزن مشفّرة، وتقدري تغيّريها من تبويب "الأمان". (لو نسيتيها: شغّلي مرة بـ `RESET_ADMIN_PASSWORD=1` مع `ADMIN_PASSWORD` الجديدة.)
**ما تبعتيش كلمة السر لحد في الشات أو واتساب.**

## لوحة التحكم (/admin)
- **المنتجات:** إضافة/تعديل/حذف، الاسم، السعر الأصلي، نسبة الخصم، القسم، **المقاسات** (S,M,L,XL أو 38-44 أو Free)، **ألوان القطعة**، رفع الصورة، إخفاء، "نفذت الكمية".
- **العروض والكوبونات:** عرض تلقائي على كل المنتجات أو قسم معين (بتاريخ انتهاء اختياري)، وأكواد خصم بتكتبها العميلة في الطلب.
- **إعدادات الموقع:** كل النصوص، اللوجو، **فيديو الصفحة الرئيسية** (رفع/استبدال/إزالة)، تعتيم الفيديو، لون اللوجو، التواصل والسوشيال، رقم فودافون كاش وإنستا باي، الشحن والشحن المجاني، **كل ألوان الموقع**.
- **الطلبات:** إحصائيات، الحالة، المقاس واللون المطلوب، واتساب للعميلة، حذف.
- **الأمان:** تغيير كلمة السر.

## النشر على Render بأسهل طريقة (Blueprint)
الملف `render.yaml` بيظبط كل حاجة لوحده (الخدمة والـ Disk والمتغيرات). كل اللي عليكي:
1. ارفعي كل ملفات المشروع (render.yaml و package.json و server.js و فولدر public) على مستودع GitHub خاص.
2. في render.com: New ← **Blueprint** ← اختاري المستودع.
3. هيسألك على قيمتين: `ADMIN_PASSWORD` (باسورد قوي) و `ADMIN_PATH` (اسم سري للوحة). اليوزر `AHMED` متحط في الملف.
4. Apply وانتظري Live، وافتحي `رابط-الموقع/اسم-المسار-السري`.

## النشر على Render يدويًا (لو ما استخدمتيش Blueprint)
1. ارفعي محتويات فولدر `misses-shop` (بعد فك الضغط) على مستودع GitHub خاص.
2. في Render: New ← Web Service ← اختاري المستودع.
3. Build Command: `npm install` — Start Command: `npm start` — النوع **Starter (مدفوع)** لأن الـ Disk مش متاح في الخطة المجانية.
4. أضيفي **Disk**: Mount Path `/var/data` وحجم 1GB.
5. المتغيرات (Environment): `ADMIN_USER` و `ADMIN_PASSWORD` (قوية) و `ADMIN_PATH` (اسم سري للوحة بدل admin) و `DB_FILE=/var/data/shop.db` و `UPLOAD_DIR=/var/data/uploads` و `TRUST_PROXY=1`.
6. بعد النشر افتحي `/admin` وظبطي الإعدادات، واحذفي أي طلبات تجريبية قبل الإطلاق.

## ملاحظات
- متغيرات البيئة الاختيارية: `PORT` و `DB_FILE` و `UPLOAD_DIR` و `TRUST_PROXY` (فعّليه 1 خلف أي استضافة عشان حد المحاولات يتحسب لكل عميلة).
- السيرفر هو اللي بيحسب السعر والخصم والشحن، ومحدش يقدر يغيّره من المتصفح.
- الفيديو: mp4 قصير (10-15 ثانية)، الأفضل أقل من 10MB، والحد 25MB.
- النشر: استضافة Node + HTTPS + **Persistent Disk** لـ `shop.db` ومجلد `public/uploads`، وخدي نسخة احتياطية منهم.
- الدفع حاليًا: عند الاستلام، فودافون كاش، إنستا باي (تأكيد يدوي من اللوحة).

## طلب العميلة
- في السلة تقدر العميلة تغيّر **المقاس واللون** والكمية وتحذف أي قطعة، وفي صفحة إتمام الطلب في ملخص وزرار "تعديل الطلب".
- رسالة الواتساب فيها **القطعة واللون والمقاس وعدد القطع فقط**، وبتتفتح جاهزة والعميلة تقدر تعدّلها قبل الإرسال. بيانات العميلة والعنوان والدفع بتوصل في لوحة التحكم.

## ركن الصيف والشتاء
- كل منتج ليه خانة **الموسم** (كل المواسم / صيفي / شتوي) من لوحة التحكم ← المنتجات.
- الموقع فيه كارتين كبار "ركن الصيف" و"ركن الشتاء" بيفلتروا المنتجات، وكمان أزرار فلتر الموسم فوق المنتجات.
- العناوين والأوصاف وصور الركنين من لوحة التحكم ← إعدادات الموقع ← "ركن الصيف والشتاء".

## قسم "منذ 2018"
تحت اللوجو في الصفحة الرئيسية. الشارة والعنوان والنص وثلاث ميزات (أناقة / راحة / خدمة) كلها بتتعدل من لوحة التحكم ← إعدادات الموقع ← قسم "منذ 2018".

## تحكم كامل من لوحة التحكم
- **أسعار وخصومات:** تعديل سعر أي منتج، خصم % لكل منتج، **تعديل جماعي** (رفع/خفض الأسعار بنسبة، أو تطبيق/إلغاء خصم على قسم أو موسم أو كل المنتجات مرة واحدة).
- **قول "في خصم" أو "مفيش خصم":** شريط الإعلان أعلى الموقع، شارة مخصصة لكل منتج (جديد / خصم خاص)، العروض التلقائية (بتظهر فوق المنتجات)، ورسالة "مفيش عروض" لما مفيش عروض شغالة.
- **التحويلات وطرق الدفع:** تفعيل/إيقاف كل طريقة (عند الاستلام / فودافون كاش / إنستا باي)، تغيير الأرقام، وملاحظة تظهر للعميلة. رقم التحويل بتاعها بيظهر مع الطلب.
- **الطلبات:** فلتر بالحالة، تغيير الحالة، ملاحظة داخلية، واتساب للعميلة، حذف.
- **الأقسام:** إظهار/إخفاء "منذ 2018" وركن الصيف والشتاء وقسم عن البراند، وكل النصوص والصور والفيديو والألوان.

## الأمان (دخول صاحبة الموقع بس)
- الدخول بـ **يوزر + باسورد** (الباسورد متشفّر). لو ما حددتيش `ADMIN_USER` اليوزر الافتراضي هو **AHMED** (مش حساس لحالة الحروف)، ولو ما حددتيش `ADMIN_PASSWORD` السيرفر بيولّد باسورد عشوائي ويطبعه مرة واحدة في الشاشة.
- `ADMIN_PATH`: بتختاري اسم سري للوحة (مثلًا `panel-x7k2`) فتفتح من `/panel-x7k2`، والمسار `/admin` يبقى مقفول.
- رسالة الخطأ واحدة ("اليوزر أو الباسورد غلط") ومبتقولش أنهي واحد غلط، وكل محاولة غلط بتتأخر، وبعد كذا محاولة بيتحظر الدخول 10 دقايق.
- اليوزر والباسورد بيتغيروا من تبويب "الأمان". كل الصفحات اللي تحت `/api/admin` مقفولة من غير تسجيل دخول.
- لو نسيتي بياناتك: شغّلي مرة بـ `RESET_ADMIN_PASSWORD=1` مع `ADMIN_USER` و`ADMIN_PASSWORD` الجداد.
- **ما تبعتيش اليوزر والباسورد لأي حد، ولا حتى هنا في الشات.**
